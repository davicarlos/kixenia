# FUN_816D8F50

**Endereço:** 0x816D8F50 · **Área:** [Kinect ID](README.md#kinect-id)

## O que faz
Apaga, na tabela de usuários (0x81A82FF4, 0x40 bytes cada), a ligação de um tipo (5 = cadastro do Kinect ID) que aponta para o valor dado, e avisa quem acompanha a tabela.
