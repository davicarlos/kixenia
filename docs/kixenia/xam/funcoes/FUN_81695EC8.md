# FUN_81695EC8

**Endereço:** 0x81695EC8 · **Área:** [Fitness](README.md#fitness)

## O que faz
Diz se a presença conta por qualquer esqueleto (e não só por um jogador estável); usada pelo contador de presença do HUD.
