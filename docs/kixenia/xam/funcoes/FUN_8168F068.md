# FUN_8168F068

**Endereço:** 0x8168F068 · **Área:** [Fitness](README.md#fitness)

## O que faz
Aloca um pacote (tag de pool 0x18000000) com o tamanho dos dados + 0x1C, escreve o cabeçalho {usuário, handle, tamanho, 1} e copia os dados. Usado por AddBodyProfileRecord e AddFitnessEvent antes de enviar ao serviço da Live (0xFB).
