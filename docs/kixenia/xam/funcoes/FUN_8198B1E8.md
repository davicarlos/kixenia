# FUN_8198B1E8

**Endereço:** 0x8198B1E8 · **Área:** [HUD, esqueleto e gestos](README.md#hud-esqueleto-e-gestos)

## O que faz
Corpo de `XamNuiPlayerEngagementUpdate`: os 2 esqueletos mais próximos (distância √(x²+z²), o rastreado ganha 0,3 m) vão para quadro+0xACC; devolve também o engajado e os índices rastreados.

## Fatos do decompilado
- Globais: 0x815F46E8, 0x815FC24C, 0x816352CC, 0x816352D0

## Chama
- Outras: `memset` (0x8172D4F0)

## Nas notas
- [Kinect-Engenharia-Reversa](../../kinect/kinect-engenharia-reversa.md): - **Escolha dos 2 esqueletos rastreados** (`FUN_8198B1E8`): para cada esqueleto calcula a distância horizontal `√(x² + z²)`; o já rastreado ganha **0,3 m** de vantagem; mínimo 0,1. Os dois mais próximos vão para **quadro+0xACC / +0xAD0** (os IDs que o sistema pede ao rastreador). Também devolve o engajado (ID, índice), a lista de índices rastreados e a contagem.
