# FUN_817FC750

**Endereço:** 0x817FC750 · **Área:** [Sensor e estado](README.md#sensor-e-estado)

## O que faz
Monta o status do sensor (estado, NTSTATUS e flags) a partir do estado do dispositivo e das configurações; sensor desligado dá 0xC000009D.

## Fatos do decompilado
- Códigos de erro: 0xC0050006
- Globais: 0x81A87FB4, 0x81AD12A0, 0x81AD12C0, 0x81AD13B4, 0x81AD1408
