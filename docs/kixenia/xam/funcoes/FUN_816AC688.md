# FUN_816AC688

**Endereço:** 0x816AC688 · **Área:** [HUD, esqueleto e gestos](README.md#hud-esqueleto-e-gestos)

## O que faz
O coração do HUD do sistema: escolhe os 2 esqueletos rastreados, roda `XamNuiSkeletonScoreUpdate` e rebaixa para PositionOnly os jogadores com alerta, solta o engajado que sumiu, roda o aceno de engajamento em cada jogador, copia o quadro para o HUD e roda o detector do gesto do guia.
