# FUN_816C1808

**Endereço:** 0x816C1808 · **Área:** [Telas](README.md#telas)

## O que faz
A checagem que toda tela 'Nui' faz: o HUD tem de estar ligado (`XamNuiHudIsEnabled`, senão 5) e o jogador que pediu passa a ser o engajado (`XamNuiHudSetEngagedTrackingID`).
