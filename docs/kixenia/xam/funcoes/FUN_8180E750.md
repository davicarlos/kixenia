# FUN_8180E750

**Endereço:** 0x8180E750 · **Área:** [Kinect ID](README.md#kinect-id)

## O que faz
Chama o callback de identidade que o título registrou (serviço+0x24) com a mensagem e o buffer, sob trava; para 0x2C006 a 0x2C008 consulta antes a 0x2C013. Sem callback: 0x8000FFFF.
