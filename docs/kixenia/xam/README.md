# XAM

O xam é a biblioteca de sistema do Xbox 360 que os jogos chamam para Kinect, avatares, perfis e interface. Tudo aqui se refere ao xam da atualização 17559, a última de varejo.

- [Funções do xam ligadas ao Kinect](funcoes/README.md): uma nota por função, com endereço, o que faz e o que chama
- [XAM-Fitness](xam-fitness.md): perfil de fitness, eventos e privacidade
- [XAM-Rede-e-Login](xam-rede-e-login.md): rede e login
- O sistema de avatares tem pasta própria: [Avatares](../avatares/README.md)
