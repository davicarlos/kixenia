# Ferramentas

O que usei para chegar às descobertas das [notas](../../docs/kixenia/README.md). Nenhuma traz arquivos da Microsoft ou dos jogos: você precisa dos seus.

| Pasta | Para quê |
|---|---|
| [avatar/](avatar/README.md) | Ler o pacote de avatares (`AvatarAssetPack.toc`), os arquivos STRB, descomprimir os blocos e transformar um modelo em `.obj` |
| [jogos/](jogos/README.md) | Descompilar todos os jogos de um HD em lote e gerar uma nota por jogo no vault, com as pendências do Xenia |
| [ghidra/](ghidra/README.md) | Scripts headless do Ghidra para o xam e os jogos (PowerPC com VMX128) |
| [kinect/](kinect/README.md) | Rodar um jogo no Xenia com o Kinect real ou com uma gravação |
| [vault/](vault/README.md) | Gerar este repositório a partir do meu vault do Obsidian |
